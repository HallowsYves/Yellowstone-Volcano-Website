# Yellowstone Project Guide

## Project Vision
An immersive, National Geographic-style educational website about the Yellowstone Supervolcano. High-impact visuals, elegant typography, and zero friction (no auth/sign-up).

## Design System (CRITICAL)
- **Source of Truth:** Always refer to `design.md` generated by Google Stitch for layouts, spacing, and color tokens.
- **Colors:** Primary background is Charcoal (#1a1a1a). Accents must use the signature 'Yellowstone Yellow' (#FFD700 or as specified in design.md).
- **Typography:** Serif for headings (editorial feel), Sans-serif for data and body text.
- **Aesthetic:** Editorial, spacious, and "quiet." Avoid "techy" or "dashboard" styles unless in the monitoring section.

## Tech Stack & Implementation
- **Framework:** React with Tailwind CSS.
- **Components:** Functional components only. Use Framer Motion for subtle "reveal" animations on scroll.
- **State:** No backend. Use local state or static props only.
- **Interactions:** Smooth scrolling between sections. Interactive "hotspots" on the caldera map.

## Development Commands
- Build: `npm run build`
- Dev: `npm run dev`
- Lint: `npm run lint`

## Code Style Prefs
- Use Tailwind for all styling (avoid CSS-in-JS).
- Maintain semantic HTML (use <section>, <article>, <header>, <footer>).
- Ensure all images have descriptive `alt` tags for accessibility.
